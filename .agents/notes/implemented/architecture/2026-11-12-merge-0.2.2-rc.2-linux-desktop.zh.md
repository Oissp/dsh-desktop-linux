# Agent Note: 0.2.2-rc.2 上游同步 —— fork 跟随 Office kit 重构并裁剪发布管线

Status: implemented

[English](2026-11-12-merge-0.2.2-rc.2-linux-desktop.md) | 中文

## Problem

上游 `master` 相对标签 `dsh-v0.2.2-rc.1` 推进了 923 个提交，并发布了 `0.2.2-rc.2`。增量改动 3479 个文件——新增 602、删除 107、修改 2684、重命名 85，另有 1 个类型变更——共 108953 行新增、33648 行删除。它围绕 LibreOffice Kit 0.2.3 重构了 Office：kit 位于 `packages/document/office-kit`，常驻的 `office_render`、`office_convert` 与 `office_recalculate` 工具取代渲染、导出与重算技能，Desktop 从 ASAR 内技能包的 assets 读取技能，不再使用 `runtime/office-skills` 副本。它还新增了 Host 拥有的桌面主题偏好、更新状态提示、Windows 重启提示、网站/COS/EdgeOne 分阶段发布管线、带显式检查与 AX 遍历上限的 CUA Windows 支持、Forge 评审界面、终端面板工具、会话 worktree 回收、Cordis rc.12，以及 zod 4.6.6 与 Stagehand 4.4.0 升级。fork 在引擎侧的分叉仍是 tsdown 构建配置与 Linux 专用打包脚本；这些文件都没有冲突。

本次合并产生 30 个冲突：19 个落在裁剪清单内的 modify/delete 冲突（workflow `pr-check-on-head-branch.yml`、Windows 安装器源文件 `window-frame.cpp` 与 `installer.nsh`、打包与发布 README 双语对、七个发布与 macOS 运行脚本，以及四个 spec），以及 11 个内容冲突（`apps/desktop-host/package.json`、`apps/desktop/package.json`、桌面 README 双语对及其配对记录、`apps/desktop/tests/main-startup.spec.ts`、`apps/desktop/tests/welcome-flow.e2e.ts`、`packages/skill/skill-office/tests/skill-office.spec.ts`、`pnpm-lock.yaml`、`pnpm-workspace.yaml` 与 `scripts/no-unknown-casts.baseline.json`）。

## Decision

**合并让上游的 Office kit、主题与更新状态界面进入 Linux 壳，并裁剪 fork 不运行的发布管线。**

再裁剪十一条上游路径，裁剪清单从 435 增至 446。桌面 rollout 相关文件——`.github/workflows/desktop-rollout.yml`、`apps/desktop/scripts/desktop-rollout.ts`、`publish-desktop-rollout-ci.ts` 与 `desktop-rollout.spec.ts`——导入已裁剪的发布模块，无法通过类型检查。`.github/workflows/cua-helper-package-windows.yml` 与 Windows 重启提示源文件（`installer/restart-banner.h`、`restart-status.h`、`restart-text.h`、`scripts/restart-banner.nsh`、`tests/fixtures/restart-status-owner.nsi`、`tests/windows-restart-status.ps1`）服务于 fork 从不构建的 Windows 流程；fork 自己的 `package-deb.yml` 直接创建 GitHub Release。

`apps/desktop-host/package.json` 跟随上游的依赖集合，移除 Host 不再导入的 `libreoffice-kit`、`home-paths`、`skill-office`、`tool-workspace-dependencies`、`cordis-plugin-loader`、`cordis-plugin-include`、`skill` 与 `tool-executor-native`，并保留 fork 对 `koffi` 的移除。Office kit 及其工具现在经上游调整的 profile 组合进入 Desktop。

`apps/desktop/package.json` 取上游的 `0.2.2-rc.2` 版本与 `zod` 4.6.6，保留 fork 的产品名、作者、主页与 Linux 专用脚本。`apps/desktop/README.md`、`README.zh.md` 与配对记录采纳上游的新段落——主题偏好、更新状态提示、ASAR 内的 Office 技能、重启提示——并重新记录配对哈希；fork 的 Linux 打包链接与裁剪目标链接保持不变。

`apps/desktop/tests/main-startup.spec.ts` 把上游的主题与更新状态用例并入 fork 的 Linux 托盘、外观控制器与菜单测试环境，包括 `nativeTheme` EventEmitter mock 与不含 `cliCommand` 项的菜单，并把窗口监听器断言调整为 fork 的应用级外观控制器行为。`apps/desktop/tests/welcome-flow.e2e.ts` 采纳围绕新 `apps/desktop/tests/harness.ts` 的上游重写；fork 的 `linux-x64` 合成项目目标移入该 harness 并补入 fork 基线。`packages/skill/skill-office/tests/skill-office.spec.ts` 采纳上游重写，其中已移除 fork 调整过的已安装 manifest 版本读取。`pnpm-workspace.yaml` 跟随上游的 LibreOffice Kit 0.2.3 发布年龄豁免与 Stagehand 4.4.0 条目，并保留指向 `patches/@deepseek-ai__libreoffice-kit@0.2.3.patch` 的 fork 补丁 pin；`pnpm-lock.yaml` 携带合并后的锁文件并去掉 `desktop-host` 的 `koffi` 条目。

三条基线条目因上游吸收其改动而移出 `sync-forked-paths.txt`：`welcome-flow.e2e.ts` 与 `welcome-startup.spec.ts` 现在与上游一致，`skill-office.spec.ts` 的 manifest 断言不再存在。`scripts/no-unknown-casts.baseline.json` 按上游改动过的文件重新生成。

**桌面版本等于引擎版本 `0.2.2-rc.2`，不追加构建计数。** fork 的发布仓库还没有 `v0.2.2-rc.2`，合并落到 `main` 后打包 workflow 会发布该版本。

## Alternatives considered

**保留 rollout workflow 与脚本并为其导入打桩。** 拒绝：它们服务于 fork 不运行的 COS、网站安装器与 EdgeOne 流程，且其发布依赖已被裁剪。

**保留此前的 `desktop-host` 依赖清单。** 拒绝：上游 Host 不再导入这些包，未使用的 workspace 依赖无法通过仓库依赖门禁。

**在 Office 技能 spec 中重新应用 fork 的 LibreOffice Kit manifest 断言。** 拒绝：manifest 读取已移除；kit 版本现在来自 `office-kit` 0.2.3，且该 spec 中与版本无关的检查已覆盖技能内容。

**保留失效的基线条目。** 拒绝：基线必须只列出仍与上游不同的文件，否则下次合并会把已被吸收的改动当成待决事项。

## Consequences

下次同步从 `dsh-v0.2.2-rc.2` 之后的上游 `master` 开始。裁剪清单记录 446 条路径，fork 基线为 75 条，其中包含新的 harness 与 Office kit 中文 README。Office 打包跟随 kit 0.2.3 并从 ASAR 读取技能；`scripts/libreoffice-packages.mjs` 仍从已安装 kit 的 manifest 推导 asar-unpack 闭包。

## Testing

`pnpm run typecheck` 通过 5 个门禁（331.91 秒）；`pnpm run build:artifacts` 通过 8 个、`pnpm run build:check` 通过 2 个。`pnpm exec vitest run apps/desktop/tests` 通过 92 个文件、1191 个用例，5 例跳过。`pnpm run test:docs` 通过其 21 个门禁。移除上游重命名遗留的三个空包目录后，`check-workspace-constraints`、`verify-package-dependencies` 与 `verify-optional-dependency-imports` 通过。对 68 个 fork 修改文件的 Oxlint 报告 0 warning、0 error；仓库级运行耗尽本机内存，未完成。
