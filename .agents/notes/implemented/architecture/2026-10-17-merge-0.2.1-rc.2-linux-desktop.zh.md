# Agent Note: 0.2.1-rc.2 合并——DeepSeek Search 与 Fetch API 到来，附临时模型标签

Status: implemented

[English](2026-10-17-merge-0.2.1-rc.2-linux-desktop.md) | 中文

## Problem

上游 `master` 在上一次同步点（`dsh-v0.2.1-rc.1`）之后前进九个提交，发布引擎 `0.2.1-rc.2`（tag `dsh-v0.2.1-rc.2`，即本次合并的目标）。增量改动 456 个文件，与上一个版本不同，这次带有实质引擎改动，覆盖四个领域：新增 `packages/web/web-deepseek-api` provider，在设置开关后暴露 DeepSeek 的 Search 与 Fetch 端点（含 transport、凭证、出口与重定向测试、语言词典，以及 `snapshots/session/deepseek-fetch` 录制会话用例）；新增 `packages/client/ui-deepseek-model-label-1017` 客户端包，为内置 DeepSeek Flash 模型标签渲染临时的「1017」徽标（含 Web e2e 场景与账号 overlay 夹具）；`ui-settings-web-search` 的 `WebSearchCard` 重构，获得自己的 CSS module 与 controller 改动；以及配套文档（能力接缝、子系统页、配置目录、持久化 schema，与 `docs/persistence-changes/2026-10-13-deepseek-search-thinking` 记录）。

合并产生一处冲突：`apps/desktop/package.json`，即 fork 的元数据块与上游版本号 bump 相遇处。本增量没有其他 fork 修改路径的文件被上游改动。

## Decision

**唯一冲突保留 fork 元数据并采用上游版本号。** `author` 与 `homepage` 继续指向 fork 仓库，版本号升至 `0.2.1-rc.2`（与引擎版本相同）。这与此前几次同步笔记记录的复现冲突同源。

**裁剪清单不变。** 本增量新增的 51 个文件全部落在引擎与文档范围内：两个新包及其测试与语言文件、Web e2e 夹具、持久化变更记录，以及 DeepSeek Search/Fetch 功能笔记。没有一个属于被裁剪的 macOS/Windows 打包或发布范围，因此清单保持 377 条。

**fork 源码不变。** `main.ts`、`locale.ts`、`update-coordinator.ts`、`desktop-build-paths.mjs`、`electron-builder.config.mjs`、`package-target.ts`、`prepare-runtime.ts` 与桌面 CLI 文件均原样通过；fork 清单中唯一被上游触及的是 `apps/desktop/package.json`，且其唯一上游改动是版本号。

**上游引擎改动原样采纳。** fork 在 `packages/` 上没有任何分叉，因此新 provider、新标签包、Web 搜索卡片重构及其全部测试均按上游原样进入代码树。

## Alternatives considered

**裁剪 `packages/client/ui-deepseek-model-label-1017`，因为该徽标是临时的。** 拒绝：裁剪清单从未包含 `packages/` 条目；该徽标是 Web 与 Desktop 客户端都会组合的内置默认 profile 包；移除它会让 fork 的客户端图为一个上游计划自行移除的包而与上游分叉。未来上游回退时反而会干净合并，而不是重新打开冲突。

**裁剪 `packages/web/web-deepseek-api`。** 拒绝：它是普通的引擎 Web provider，除非 profile 启用否则惰性，而 fork 的引擎载体在 `packages/` 上没有分叉。裁剪清单的存在目的是打包与平台范围，不是可选产品功能。

**因为客户端图变了就把桌面版本加上 `.N` 后缀。** 拒绝：运行手册只在 fork 壳代码有改动时才加 `.N` 后缀。本次同步没有壳代码改动，因此桌面版本等于引擎版本。

## Consequences

下一次同步从上游 tag `dsh-v0.2.1-rc.2` 开始。裁剪清单保有 377 条路径。

fork 现在随附 DeepSeek Search 与 Fetch provider 及临时模型标签，两者都只能通过引擎自身的组合启用。它们都不触及 Linux 壳，因此 `package-deb.yml` 无需改动，更新器继续从版本的预发布段推导频道。

`docs/persistence-changes/2026-10-13-deepseek-search-thinking` 下的新持久化变更记录是引擎 schema 记录的文档；fork 按上游原样携带，因为 fork 不在持久化上分叉。
